# Rule: Enterprise Sales and Customer Positioning

Audience: enterprise buyers, evaluators, security and procurement reviewers.

## Focus

Business pain in the buyer's language, ROI with transparent inputs, security and compliance posture (only what is true and documented), integration effort and time to value, pilot structure.

## Must exclude

- Internal margins, cost structure, runway
- Investor deck content, fundraising status, equity
- Source code and internal architecture detail beyond what a security review requires
- Roadmap commitments presented as promises
- Other customers' names or data without written permission

## Claims discipline

- Compliance claims (SOC 2, ISO 27001, HIPAA, etc.) only if certification or attestation exists. Otherwise write "in progress" or omit.
- SLA figures only if contractually backed.
- Roadmap items must be labeled "planned, not committed".
- ROI figures show inputs and mark customer-supplied versus our assumptions.

## Leak check (append to every output)

List excluded items, any claim needing documentary proof, and any roadmap statement for the human to confirm.
