# Contributing

Contributions that make the template more useful to real startups are welcome.

## Good contributions

- New or improved section templates, based on something you actually used
- New audience rule files or skills
- Fixes to unclear instructions
- A worked example under `examples/` using a clearly fictional company

## Ground rules

- No real company data, customer names, or personal information in any contribution.
- Templates must not invent facts. Use `[TBD: ...]` placeholders.
- Keep Markdown lint-clean (see `.github/workflows/docs_lint.yml`).
- Open an issue before large structural changes.

## Commit style

Conventional commits: `docs:`, `feat:`, `fix:`, `chore:`.
